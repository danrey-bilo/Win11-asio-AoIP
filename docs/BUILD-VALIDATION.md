# Проверка разделённого репозитория

Дата: 24 сентября 2026. Проверен отдельный проект Windows с AoIP-lib,
подключённой через `AOIP_SOURCE_DIR`, а затем из закреплённого git submodule,
и отдельно установленным ASIO SDK.

Среда: Windows 11 x64, LLVM-MinGW 20260616 / Clang 22.1.8, CMake 4.4.3,
Ninja 1.13.2, WiX Toolset 7. SDK использован локально и в репозиторий не включён.

| Проверка | Результат |
|---|---|
| Release CMake/Ninja | `PiAoipAsio.dll`, `PiAoipControl.exe`, `smoke_host.exe`: собраны |
| CTest | Тесты конфигурации: 1/1 |
| `scripts/build.ps1` в отдельном чистом каталоге | Полная сборка и CTest завершились успешно |
| Чистая сборка с `external/AoIP-lib` из GitHub | Полная сборка и CTest: успешно, без `AOIP_SOURCE_DIR` |
| `packaging/msi/build-msi.ps1` | Собран `PiAoIP-2.1.0-Windows11-x64.msi` |
| Проверка MSI через WiX / Windows Installer ICE | Завершилась с кодом 0 |

В MinGW-сборку включён статический C++ runtime. Проверка сборки не меняла
регистрацию ASIO/COM и не устанавливала новый MSI поверх работающего драйвера.
Установка на чистую другую машину Windows и повторный аппаратный прогон
латентности после разделения не заявляются. Для них см. [TESTING.md](TESTING.md).

Бинарники не публикуются в этом исходном репозитории. Условия отдельного SDK
и распространения объединённой сборки — в [ASIO-SDK.md](ASIO-SDK.md).
